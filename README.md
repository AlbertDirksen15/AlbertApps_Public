# AlbertApps — публичные веб-сборки

Этот репозиторий предназначен **только для готовых статических файлов** приложений, которые можно запускать через GitHub Pages. Здесь не ведётся разработка исходного кода.

## Структура

- `/codetrainer/` — публичная демоверсия CodeTrainer
- `/noma/` — публичная демоверсия Noma
- `/learningtracker/` — публичная демоверсия LearningTracker
- `/index.html` — каталог опубликованных приложений

Каждая папка приложения автономна и содержит только необходимые для запуска HTML/CSS/JS/ресурсы. Сборки должны публиковаться автоматически из соответствующих **приватных исходных репозиториев** через GitHub Actions.

## Безопасность

- Не коммитить исходные проекты, токены, приватные заметки, конфигурацию с секретами или данные пользователей.
- Демо не имеет доступа к личному хранилищу.
- GitHub Pages публичен: скрытый URL или пароль, проверяемый только JavaScript, **не обеспечивает защиту**.
- Личный режим требует настоящей авторизации и защищённого отдельного хранилища; при отсутствии такого механизма его не следует публиковать в этом репозитории.
- Любой JavaScript в опубликованной сборке доступен посетителям для анализа.

## Статус

Создан каталог приложений. Автоматические сборки и публикация из приватных проектов ещё не настроены. Ссылки на приложения будут работать после добавления соответствующих статических сборок.
